# Concrete, pinned dependencies for running Fesium and working on it.
#
# Exact pins on purpose. pyproject.toml carries the abstract ranges - what the
# package needs in order to work - and this file carries the concrete versions
# an install actually gets. Two reasons it matters here: CI reproduces exactly
# what a contributor runs, and Semgrep's supply-chain analysis skips any
# dependency that is not pinned. It was skipping all of them, so 17751
# vulnerability rules were running against zero packages.
#
